Codes used for "Azimuthal anisotropy across Australasia from joint SKS and direct S splitting measurements" by Valencia, N., Wolf, J., & Romanowicz, B.

Order to run scripts: 

1. download_SKS_phase.py and download_S_phase.py 

2. network_waveform_data_2.py

3. network_waveform_window_2.py

4. network_measure_waveform.py

Final station classifications in station_keys.py
